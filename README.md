## Introducción y Misión
Este proyecto inicio a partir de un recuerdo nostalgico mio sobre un juego de mi infancia, lalmado "Garfield defense" tambien encontrado a dia de hoy como "Garfield War", es un juego sencillo y muy entretenido, aunque avanzado para su epoca debo admitir, es un juego 2d donde uno debia defenser su base y atacar la del rival.

Si bien esta inspirado en el, se distinguira mucho del juego orginal para evitar un Copy-Paste del mismo o incluso peor, una demanda por Copyrigth, ademas de que perderia en efecto, lo mas maravilloso de construir un software o projecto por si mismo, añadirle eso brillo magico que cada uno de nosotros posee.

## CU Madre y Ciclo de Vida del Juego
Este documento le servirá como una guía para el proyecto así no se marea ni confunde, sumado a que podrá desplazarse entre documentos sin perder el foco ni el contexto.

Representa el flujo integral del usuario dentro de la aplicación: el jugador inicia en un Menú Principal, navega por un mapa temático para jugar niveles instanciados, gestiona una economía local ("Patas de pollo") para desplegar tropas y defender su base, y al finalizar la partida el sistema calcula una economía global ("Donas Doradas") que persiste para comprar mejoras. 

A continuacion se estructura todo. Usted debería leer lo que se encuentra en este documento, así también como ver los diagramas (si es que los hay, ya que se encontraran en una version 2 del proyecto), y luego dirigirse a los ACCESOS DIRECTOS para así poder recorrerlos 1x1. También puede volver si lo desea o se olvida la organización y jerarquía de los mismos.
